# ✈️ Sky Jet Explorer 3D (고해상도 제트 여객기 시뮬레이터 & 해상 비상착수 물리 엔진)

**Sky Jet Explorer 3D**는 맥도넬 더글러스 **DC-10(삼발기)**, **MD-80(후방 쌍발기)**, **에어버스 A320**, **보잉 B747-400 점보**, **초음속 여객기 콩코드(Concorde)** 등 총 5종의 제트 여객기를 정밀 조종하여 실제 국제공항의 게이트 탑승, 탑승교(Jet Bridge), 유도로 주행, 활주로 이착륙 및 해상 비상착수(Water Ditching)를 완벽하게 체험할 수 있는 3D 비행 시뮬레이션 게임입니다.

Three.js 기반의 고성능 3D WebGL 엔진으로 구현되어 **웹 브라우저에서 즉시 실행** 가능하며, **Flutter 모바일 앱**으로도 패키징되어 스마트폰에서 플레이할 수 있습니다.

## 🌟 주요 업그레이드 및 특징

1. **5종 제트 여객기 정밀 CAD급 모델링 & 실시간 가동 조종면 (Control Surfaces)**:
   - **DC-10 삼발기 (Trijet)**: 주익 2기 터보팬 + 수직 꼬리날개 관통 1기 터보팬, 가동 방향타 및 승강타.
   - **MD-80 쌍발기 (Twinjet)**: 동체 후방 좌우 2기 터보팬 엔진, T-Tail 수평미익, 가동 T-엘리베이터.
   - **A320 제트기 (Modern Twinjet)**: 샤클렛(Sharklets) 윙팁, CFM56 언더윙 트윈 엔진, 2단계 가동 에일러론.
   - **B747-400 점보 (Jumbo Jet)**: 상층 2층 덱(Hump) 조종석, 4발 대형 제트엔진, 24개 고해상도 객실창, 4열 중형 랜딩기어.
   - **콩코드 초음속기 (Supersonic)**: 마하 2.0 초음속 드룹 노즈(Droop Nose), 오기브 슬렌더 델타익, 가동 엘레본(Elevons: 에일러론+승강타 통합면), 하부 듀얼 사각 램젯 박스 & 애프터버너 코어 링.
   - **실시간 가동 조종면 (Dynamic Flight Surfaces)**:
     - **에일러론 / 엘레본**: `A` / `D` 입력 시 좌우 주익 플랩이 반대로 꺾이며 실감나는 롤 기동.
     - **승강타**: `↓` (상승) / `↑` (하강) 입력 시 꼬리날개 승강타가 상하로 회전.
     - **방향타 (Rudder) & 노즈 기어**: 좌우 선회 시 수직 꼬리날개 방향타와 전방 바퀴가 조향각에 맞춰 연동.

2. **지상 360도 무한 조향 (Infinite 360° Taxiing)**:
   - 기존의 180도 조향 락 버그를 완전 해결하여, 유도로 및 활주로에서 끊김 없이 360도 원을 그리며 자유롭게 방향을 선회할 수 있습니다.

3. **바다 비상착수 (Water Ditching) & 해상 추락 물기둥 (Massive Water Geyser) 물리**:
   - **허드슨강의 기적식 비상착수**: 완만한 강하율과 속도로 수면에 접근 시 동체 파손 없이 부드럽게 수면 활주 물보라를 일으키며 감속, 수면 부유 둥실거림(Bobbing) 및 285명 전원 구명정 탈출 성공 모달 팝업.
   - **고속 격돌 물기둥**: 급강하 또는 고속으로 바다에 추락할 경우, 수면 충격파 링과 함께 하늘 높이 치솟는 거대한 물기둥(Massive Water Geyser)과 기체 파쇄 분해 연출.

4. **1인칭 / 3인칭 체감 속도감 & 고속 공기역학 시각/음향 효과**:
   - **동적 속도 FOV**: 시속에 따라 카메라 시야각이 60도에서 최대 86도까지 시원하게 확장되어 주변 사물이 휙휙 스쳐 지나가는 실제 속도감 체감.
   - **3D 고속 기류 스트림라인 (Speed Lines)**: 180가닥의 미려한 공기 기류선이 기체 주변을 관통.
   - **마하 0.65+ 콕핏 미세 풍압 진동 & 풍절음**: 580 km/h 이상에서 조종석 미세 떨림과 가변 밴드패스 풍절음(Wind Rush Audio Synthesis 600~2000Hz) 실시간 발생.

5. **버튼 먹통(Unresponsive Buttons) 완전 해결**:
   - 모바일 웹뷰(WebView)나 특정 환경에서 발생하던 `DOMContentLoaded` 미발생 버그를 해결하기 위해 `document.readyState` 즉시 검사 및 HTML 인라인 `onclick="window.switchPlane(...)"` 이중 안전장치를 구축하여 모든 버튼이 100% 즉시 클릭됩니다.

## 🎮 키보드 조작 가이드

| 조작 키 | 기능 설명 |
| :--- | :--- |
| **0 ~ 9** | **엔진 스로틀 출력 조절** (`0`: 0% 정지 ~ `9`: 90% 순항 출력) |
| **Space / Shift** | **최대 전출력 100% (FULL THROTTLE)** |
| **W** | 앞으로 빠르게 가속 |
| **S** | 제동 및 브레이크 / 지상 역추진 |
| **A / D** | **방향 조절** (공중: 좌우 롤 & 에일러론 가동 / 지상: 360도 무한 노즈 휠 & 러더 조향) |
| **↓ (아래 화살표)** | **기수 상승 (Pitch Up)** - 엘리베이터 상향 전개, 180 km/h 이상에서 이륙(Rotate) |
| **↑ (위 화살표)** | **기수 하강 (Pitch Down)** - 엘리베이터 하향 전개 |
| **G** | **랜딩 기어 접기/내리기 (Gear Up / Down)** |
| **C** | **카메라 시점 변경** (3인칭 후방 시점 ↔ 1인칭 조종석 시점) |
| **P** | **기종 교체** (DC-10 ↔ MD-80 ↔ A320 ↔ B747 ↔ Concorde 5종 순환) |
| **📱 모바일** | 화면 좌측 가상 조이스틱 / 우측 BOOST & BRAKE 버튼 |
